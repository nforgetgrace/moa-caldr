# v0.1.6 검증 · 2026-09-10

## 변경

- 앱의 월·주 달력에서 `+N`으로 일정을 숨기지 않는다. 모든 일정 행을 표시하고 주 높이를 늘리며, 화면을 스크롤할 수 있다. 긴 제목은 칸 너비에 맞게 말줄임하고 아래 일정 목록에서 전체 제목을 제공한다.
- 9/11~12 같은 여러 날 일정은 앱과 월간 위젯에서 날짜 칸을 가로지르는 하나의 막대로 표시한다. 주 경계에서는 별도 이어지는 막대로 표시하며 제목에 이어짐 기호를 붙인다. 다른 계정의 같은 제목 일정을 합치지 않는다.
- 위젯은 최대 3개 제목 행과 날짜별 초과 개수를 유지한다. 한 막대를 중간에서 잘라 숨기지 않으며, 작은 위젯에서는 공간에 맞춰 제목 수를 줄인다. 막대 위 어느 날짜를 눌러도 실제 누른 날짜로 앱을 연다.
- Google·네이버 저장이 네이버 백그라운드 조회를 기다리던 잠금을 분리했다. 조회끼리는 직렬화하되 Google Provider 쓰기는 별도로 처리하고, 네이버 저장도 진행 중인 REPORT가 끝날 때까지 기다리지 않는다.
- 조회 시작 이후 저장·삭제·재연결·연결 해제가 발생하면 이전 조회의 결과와 오류를 버린다. 새 일정을 지우거나 삭제한 일정을 되살리거나 해제한 계정 정보를 복원하는 일을 막는다. 네이버 저장 자체의 서버 응답은 계속 확인하며 기존 ETag 보호를 유지한다.
- 기존 캐시 유지, 계정 선택, 서비스 색상, 직접 요청할 때만 상단 스피너 표시, 로그인 성공 뒤 입력 창을 닫는 동작을 유지한다.

## 재현과 검증

전용 API 35 AVD `moa_calendar_api35`, `emulator-5554`에서 수행했다. 데이터와 인증은 격리된 fixture이며 실사용 계정은 사용하지 않았다.

| 검사 | 결과 |
| --- | --- |

| 저장 이후 오래된 REPORT 도착 | 새 일정 캐시 유지, 다음 유효 조회로 초기 동기화 완료 |
| REPORT 도중 삭제 및 연결 해제 | 작업이 대기하지 않음. 삭제 일정 복원 없음, 해제 계정 캐시/오류 복원 없음 |
| 로그인·인증 실패·재로그인·재시도 | 기존 회귀 검사 통과. 인증 확인 뒤 창 닫힘, 같은 계정 캐시 유지 |
| 실제 홈 위젯 날짜 클릭 | 최근 Activity 유지, 날짜 변경, Activity 종료 후 재진입에서도 캐시 유지, 자동 스피너 없음 |
| 9/11~12 연결 막대 | 앱과 위젯에서 제목 한 번, 두 날짜 너비의 막대 표시 |
| 앱 6개 일정·위젯 6개 일정 | 앱은 6개 행, 위젯은 3개 제목 + `+3` 표시 |
| 주·월 경계 | 주말 일정은 토요일/다음 주 일·월에 이어짐. 9/30~10/2 일정은 같은 주에서 연결 |
| 연결 막대의 토요일 부분 클릭 | 실제 위젯 막대 좌표를 눌러 9/12 선택과 해당 일정 2개 표시 확인 |
| 실제 앱에서 Google 일정 새 등록 | 임시 Provider 캘린더에 저장 후 편집기 닫힘, 6개에서 7개로 증가 및 새 제목 표시 |
| 100%·130% 글자 크기, 주 보기 | 수동 스크린샷 검토. 행 높이 확장, 연결 막대 및 표시 개수 유지 |
| 단위 검사 | 86개 통과, 실패/오류/건너뜀 0 |
| Android lint 및 APK | 오류 0, 경고 36. 앱·테스트 APK 빌드 성공 |

추가된 주 배치 단위 검사는 종료일 제외, 자정 종료, 야간 일정, UTC 종일 일정과 현지 시간 일정, DST, 0초 일정, 겹침, 주·월 경계, 동일 제목 분리, 입력 순서 변경, 앱 12개 전체 표시, 위젯 용량별 초과 개수, 연결 막대 보존을 검사한다. 이전 일별 미리보기 함수와 사용되지 않는 XML은 새 공통 주 배치로 대체했다.

저장 회귀 검사는 실제 편집기와 저장소를 사용하되, 네이버 HTTP 응답은 interceptor로 제어한다. Google 쓰기는 실제 Android Calendar Provider에 임시 계정 캘린더를 만들어 확인한다. 따라서 실제 네이버 서버 PUT이나 Google 클라우드 업로드 성공을 검증했다는 의미는 아니다. 음성·좌표에 의존한 저장 검사가 아니라 접근성으로 필드를 입력하고 저장 완료 및 캐시를 확인한다.

위젯은 [Android RemoteViews가 지원하는 FrameLayout·LinearLayout·TextView](https://developer.android.com/reference/android/widget/RemoteViews)를 사용한다. 1~7일 너비의 리소스로 실제 가로 막대를 그리고 별도 날짜 클릭 영역을 겹친다. 텍스트를 이미지로 렌더링하지 않는다. lint 경고는 기존 버전·스타일·속성 호환성 권고와 7개 위젯 너비 리소스의 10sp 글자 크기 권고 등을 포함한다.

검사 종료 후 임시 Provider 캘린더·일정과 캐시를 제거하고 원래 설정과 글자 크기를 복원했다. 테스트 APK를 제거하고 전용 에뮬레이터도 종료했다. 테스트 APK는 앱 APK에 포함되지 않는다.

## 남은 범위

실제 계정의 Google/Naver 서버 왕복, Galaxy/Samsung 런처, Android 8~14 실기기, 대규모 캘린더, 장시간 절전·재부팅·프로세스 종료 중 동기화는 이번 환경에서 검증하지 않았다. 네이버 저장 요청 자체는 서버 응답·권한·네트워크 상황에 따라 지연되거나 실패할 수 있다. 짧은 날짜 칸에서는 긴 제목과 이어짐 기호가 말줄임될 수 있으며 전체 정보는 날짜별 목록으로 확인한다. 배포용 서명과 스토어 출시는 수행하지 않았다.
