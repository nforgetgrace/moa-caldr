# v0.1.11 — 월 위젯 안에서 전달·다음달 이동

월 위젯 제목 양옆에 ‹ › 화살표를 추가했습니다. 화살표를 누르면 위젯이 앱을 열지 않고 그 자리에서 전달·다음달을 그리며, 앞뒤 12개월까지 이동합니다. 제목은 어느 달이든 연도 없이 월만 표시합니다(`8월`). 이번 달이 아닐 때 제목을 누르면 이번 달로 돌아옵니다. 이번 달일 때 제목은 이전처럼 오늘 날짜로 앱을 엽니다.

선택한 달은 위젯마다 따로 기기에 저장하며, 선택한 날짜에만 유효합니다. 날짜가 바뀌면 다음 갱신(자정 날짜 변경 브로드캐스트 또는 30분 주기 갱신)에서 자동으로 이번 달로 복귀합니다. 오늘 표시, 날짜 탭, 하단 "오늘 N개의 일정", 새로고침, 다가오는 일정 위젯, 캘린더 색상은 그대로입니다.

## 검증 범위

- 단위 테스트(`WidgetMonthTest`): 이동·경계(±12개월)·자정 만료·월만 표시하는 제목·6주 격자 조회 범위·저장 형식 왕복.
- 격리 에뮬레이터(`widget_month` 시나리오): 실제 홈 화면 위젯에서 이전 달 2회, 이번 달 복귀, 다음 달 이동과 각 달의 일정 표시, 위젯별 저장값, 어제 선택한 달의 만료, 이번 달 제목 탭으로 앱 진입.
- 기존 `widget`, `calendar_colors` 시나리오를 새 위젯 레이아웃으로 재실행했습니다.
- APK 메타데이터·서명·SHA-256, 단위 테스트·lint 집계는 `docs/verification/v0.1.11/`에 기록합니다.

## 확인 한계

네이버에서 한 번도 조회하지 않은 달은 공유 캐시에 있는 일정만 표시합니다. 위젯이 다른 달을 표시하는 동안에도 조회 범위는 오늘 기준 범위와 표시 달 격자를 합친 구간입니다. 실제 자정 경과는 어제 날짜로 저장한 선택값으로 대체 검증했습니다. `calendar_colors` 시나리오는 다른 시나리오 직후 쉬지 않고 연달아 실행하면 앱 종료가 끝나기 전에 시작되어 첫 화면을 찾지 못할 수 있으며, 단독 실행에서는 통과합니다.

## 구현 근거

- [RemoteViews](https://developer.android.com/reference/android/widget/RemoteViews): 위젯 레이아웃에 허용되는 뷰 클래스. 여백용 `View`는 허용되지 않아 `TextView`로 대체했습니다.
- [App widgets](https://developer.android.com/develop/ui/views/appwidgets): 위젯 내부 버튼의 브로드캐스트 PendingIntent 처리.
